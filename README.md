# Michael Patterson — Portfolio

Personal portfolio focused on AI automation, connected business systems, and cybersecurity.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

Expected address after GitHub finishes publishing: https://mikeyp263.github.io/PortfolioMP/

## Files

- `index.html`: profile, projects, and background
- `style.css`: responsive design
- `script.js`: interactive workflow walkthroughs
- `portrait.svg`: embedded original portfolio headshot

No dependencies or build step. All links to local assets are relative for GitHub Pages project hosting.

The walkthroughs are illustrative and do not connect to live systems or contain customer data. Project summaries describe scope rather than claiming measured business outcomes.
